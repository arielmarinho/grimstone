# Sistemas Grimstone (resumo)

- Classe definida pela arma (estilo Rucoy): trocar arma = trocar classe/sprite
- Skills sobem com uso: Espada, Machado, Defesa (futuro: Maça, Distância, Magia)
- Arma embutida no sprite; customização por troca de textura (cabelo/túnica, 5 cores)
- Cores bônus obtíveis in-game: mostrar travadas com cadeado + requisito (colecionável)
- Combate: hitbox no golpe; mobs com HP bar flutuante, IA wander/chase/attack, respawn
- XP fórmula Tibia-like; tela de skills estilo Rucoy (cards com progresso)
- HUD flutuante: nome acima da barra; cores verde→amarelo→laranja→vermelho conforme HP
- Dados serializáveis (JSON) desde o início — preparado pra servidor autoritativo futuro
- Montaria (futuro): sprite separado EMBAIXO do personagem
